# ClipCerto

**Cortes dos seus vídeos longos, com IA, no seu PC.** App grátis para Windows 10 e 11.

O ClipCerto encontra os melhores momentos do seu vídeo, corta na vertical seguindo o rosto, legenda palavra por palavra e publica no seu TikTok. A transcrição e a montagem rodam no seu computador.

## Baixar
➡️ **[Baixar a versão mais recente](https://github.com/clipcerto/clipcerto/releases/latest)** (arquivo `ClipCerto-Setup-x.y.z.exe`)

1. Abra o arquivo baixado. Não pede senha de administrador.
2. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital paga.
3. Abra o ClipCerto pelo menu Iniciar e siga a tela de boas-vindas.
